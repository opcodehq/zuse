The home screen lists chats from every connected computer and Zuse Cloud. Use **Search chats** to filter them. Archived chats move to **Archived**, where **Restore** brings them back.

## Start a chat

Tap **New chat**, then choose:

1. **Run on**: a connected computer, or **Cloud** when you are signed in.
2. **Project**: a project on that computer, or **Add a project**.
3. **Where** the agent works: **New worktree**, **Main checkout**, **Existing branch**, or **Existing worktree**.
4. The agent and its access: **Ask before changes**, **Allow edits**, **Allow edits & commands**, or **Full access**.

Write the first message, attach photos or files if you need them, and send. **Plan mode** in the chat options asks the agent to plan before it changes anything.

## Follow and steer

Agent output streams into the chat as it arrives. While the agent works, the send button becomes **Stop response**. A message you send while the phone is reconnecting shows as queued until the computer confirms it.

## Answer requests

When an agent needs you, the request appears in the chat:

- For a permission request, read the command or tool, then choose **Allow once** or **Deny**.
- For a question, pick the answers and choose **Send answers**.
- For a plan, read it and choose **Approve plan** to let the agent continue.

<Callout title="Agents belong to the computer">
The phone lists the agents installed and signed in on the selected computer. Install an agent CLI there before expecting it on your phone.
</Callout>
