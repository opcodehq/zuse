If your devices are on the same tailnet, Zuse can offer its tailnet address to paired devices. It works at home and away, needs no Zuse account, and is never exposed to the public internet. Tailscale and Headscale both work.

Before you begin, install Tailscale (or a Headscale client) on the computer that runs Zuse and sign in.

## Turn it on

1. In the desktop app, open **Settings → Remote access**.
2. Under **This computer**, turn on **Tailscale**.

While Tailscale is not running, the row reads **Start Tailscale or Headscale on this computer to use it.** and the switch is unavailable. Once it is on, the row shows **On ·** followed by the computer's tailnet address, and the status reads **Reachable at home and away**. If Zuse is still waiting for an address, it shows **On · waiting for Tailscale**.

Then pair devices as usual with **Connect device**; see [Pair a phone](/remote/nearby-pairing/). Devices learn every route the computer offers, so a phone paired at home keeps working over Tailscale when you leave, and moves back to Wi-Fi when you return.

On a headless computer, `zuse serve --lan` offers both the local network and the tailnet.

## Tailscale HTTPS

Browsers need an HTTPS page. On the local network Zuse uses a certificate generated for the computer, which browsers warn about. Tailscale HTTPS publishes the web client on your tailnet with a certificate browsers already trust.

In **Settings → Remote access**, open **Advanced settings** and turn on **Tailscale HTTPS**. The switch appears while network access is on and Tailscale is available. On a headless computer, run:

```sh
zuse serve --lan --tailscale-serve
```

Browser links from `zuse pair` then prefer the Tailscale HTTPS address.

## Turn it off

Turn off **Tailscale**. Devices using the tailnet address disconnect; other routes keep working.
