Paired devices reconnect on their own after sleep, a network change, or a dropped connection, and pick up where they stopped. Most problems come from the computer being unreachable or the pairing no longer being valid.

## Quick order

1. Keep the computer awake and online, with the desktop app or `zuse serve` running.
2. Check that a connection is on: **Settings → Remote access** should not read **Only this computer can use Zuse**. On a headless computer, run `zuse status` and look at its network routes.
3. Let the device retry, or use its retry action.
4. Pair again only if the computer no longer accepts the device.

## The link or code does not work

- **Code expired:** codes last ten minutes. Choose **New code** in **Connect device**, or run `zuse pair` again.
- **The code was created, but no address can reach this computer yet:** turn on **Wi-Fi** or **Tailscale** first.
- **This link only works on this computer:** start `zuse serve` with `--lan` or `--account`.
- A code works for one device. Make a new one for each device.

## The computer cannot be reached

- On the same network, both devices must be allowed to talk to each other. Guest and office Wi-Fi often isolate devices; use Tailscale instead.
- For Tailscale, the row must show an address, not **On · waiting for Tailscale**. Start Tailscale on both devices.
- If **Settings → Remote access** shows **Network access could not start. Turn it on again from Devices.**, turn the connection off and on again.

## The pairing is no longer accepted

If the device was revoked, or its saved pairing is invalid, retrying cannot fix it. The web client says **This computer no longer accepts this pairing**. Pair the device again with a new link. In the web client, forget the old computer in **Settings → Remote access** first.

## The computer's identity changed

If a saved computer now answers with a different identity, Zuse stops instead of connecting. Confirm it is the computer you expect, then add it again with a new link.

## Versions do not match

An account-linked computer on an older version shows **Update Zuse on this computer to connect.** Update Zuse on that computer, then connect again.

## An action may have completed

If the connection drops while an action is in flight, Zuse does not send it again automatically. The web client says the change may have completed before the connection closed. Check the current state before you retry.
