Open **Settings → Keyboard shortcuts** to record a new shortcut, reset one row, or choose **Restore defaults**. Zuse refuses a recording that conflicts with another shortcut and names the shortcut that already uses it. Press `⌘/` anywhere to see the shortcut reference.

Your shortcuts are saved with your other preferences. See [User settings](/reference/settings#where-preferences-are-stored).

## Composer behavior

By default, `Enter` sends a message, and a message sent while the agent is working joins the queue. `⌘Enter` sends it into the running turn right away, and `⌥Enter` always queues. Turn on **Direct steer** in **Settings → General** to make `Enter` send to a running agent right away.

`Esc` stops the agent only when you press it twice. **Settings → General** also lets you choose whether `Enter` or the modifier key sends messages and whether `Esc` stops the active agent when no dialog or menu is open.
