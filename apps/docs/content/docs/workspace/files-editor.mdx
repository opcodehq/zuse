The **Files** panel shows the active chat's checkout as a directory tree. Select a file to open it in the workspace pane beside the conversation. The tree marks Git changes, including deleted and renamed files, so repository state stays visible while you browse.

## Open the Files panel

- Choose **Files** from the **+** menu in the workspace pane, or from the launcher an empty pane shows.
- Type `/files` in the composer.
- Press `⌘E` (`Ctrl+E` on Windows and Linux) to show or hide the file tree.

## Find and manage files

The panel header has **New File**, **New Folder**, and **Search files**, which filters the tree by name. To search the whole checkout from anywhere, press `⌘P`: it opens the command palette on its **Files** tab.

Shift-click or `⌘`-click to select several entries. Drag files or folders onto another folder to move them. Right-click an entry for:

- **Add to chat**, which adds it to the composer
- **Copy path** (**Copy paths** for a selection), which copies the full path
- **Rename…**, which edits the name in place
- **Delete…**, which asks for confirmation; deletion cannot be undone
- **Reveal in Finder** (**Reveal in File Explorer** on Windows, **Reveal in Files** on Linux)
- **Show hidden files** or **Hide hidden files**

New files and folders can be created only in a checkout on this computer.

## Views

The editor toolbar changes with the file type:

- **Diff** and **Edit** appear for a changed text file that Git can compare. **Diff** shows the change; **Edit** is the syntax-highlighted editor.
- Markdown files open as a rendered preview. Use **Show Markdown code** to edit the source and **Preview Markdown** to return.
- HTML files offer **Preview / Edit** to switch between the rendered page and its source.
- **Enable word wrap** or **Disable word wrap** toggles long-line wrapping.
- **Reveal file in tree** selects the open file in the Files panel, and **Open in** lists the installed applications that can open it.

Common image formats, including PNG, JPEG, GIF, WebP, SVG, BMP, and TIFF, open as image previews. Binary files, very large files, and files with unsupported encodings show a message instead of an editor. Symlink targets and files with mixed line endings open read-only.

## Save safely

Press `⌘S` to save. Zuse checks the file on disk before writing so it does not silently overwrite a newer external edit. The toolbar shows **Save failed**, **Save conflict**, **Changed on disk**, or **Deleted on disk** when something needs your attention; your editor buffer is kept in every case.

When the open file changes outside Zuse, a banner says **This file changed outside Zuse.** Choose **Keep Editing** to keep your version, or **Reload from Disk** to load the new content. If you have unsaved edits, Zuse asks again before **Discard & Reload** replaces them.

## Comment on code

Click the gutter beside a line, or place the cursor and press `⌘⇧A` (**Annotate selection**), to open a comment box. Describe the change and click **Comment**. The comment and its line are staged in the composer's **Annotations** tray for the current chat, where you can edit or remove it before sending. See [Context and attachments](/composer/context-attachments).

## Add context to a prompt

Use `@` in the composer to find a file without navigating the tree. Mention search is scoped to the same active checkout, so a worktree chat does not attach the main checkout's version.
