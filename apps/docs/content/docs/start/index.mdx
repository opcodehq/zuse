## The shortest path

1. [Install Zuse](/start/install) and open it.
2. Connect at least one supported agent.
3. Open a Git repository as a project.
4. Start a chat, choose its workspace and access, then describe the outcome you want.
5. Review the agent's edits in the **Diff** panel, run the project, and commit or open a pull request when the work is ready.

Zuse keeps your projects, chats, and their full history on your computer. Closing the window does not turn a finished conversation into disposable terminal output.
