A good first task is small enough to review but meaningful enough to touch the real project: fix a focused bug, add one test, or explain and improve one workflow.

## 1. Open the project

Choose **New project** in the sidebar and open the repository's folder, or clone it. Zuse adds it to the sidebar and reads its Git state. Opening a project does not copy or move the repository.

## 2. Start the chat

Choose **New thread** in the sidebar (`⌘N`, or `Ctrl+N` on Windows and Linux). Before sending, check the controls on the composer:

- **Agent and model**: the chip shows the model and its reasoning level. Open it to pick another agent or model.
- **Workspace**: **Worktree** gives the chat a fresh isolated branch, **Local** uses the main checkout, and **Cloud** runs the chat on a cloud computer when your account has Cloud.
- **Access**: **Ask for approval**, **Approve for me**, or **Full access**. Your choice also becomes the default for new chats.

For an implementation task, use a worktree. It keeps the task on its own branch and leaves your main checkout free for other work. For a read-only explanation, the main checkout is usually enough.

To continue work you started elsewhere, use **Import chat** to pick up a recent conversation from a supported agent app on this computer.

## 3. Give the agent a verifiable outcome

Include the problem, the expected result, and how you want it checked.

```text
The empty state in the activity panel does not update after the first item is added.
Find the cause, fix it without changing the surrounding layout, and run the focused tests.
Tell me which behavior you verified and call out any checks you could not run.
```

Type `@` to mention a file. You can also attach images and other files, or drop them onto the composer.

## 4. Follow the work

The transcript shows the agent's messages, tool calls, edits, and questions as they happen. You can:

- answer a question inline;
- allow or deny a requested action, for this chat or always in this project;
- queue another message while the agent works, or press `⌘Enter` to send it into the running turn now;
- stop the turn by pressing `Esc` twice;
- open a changed file, the diff, or a terminal beside the chat.

Turn on Plan mode (`⇧Tab`) before sending when you want the agent to explore and propose a plan before it edits anything.

## 5. Review the result

Open the **Diff** panel on the right and read the changes. Run the relevant checks in **Terminal**, and send corrections in the same chat if needed. When the branch is ready, commit, push, and open a pull request. See [Changes and pull requests](/workspace/changes-pull-requests).

## What persists

The project, the chat, its conversations, tool results, and its worktree stay available after you restart the app. An agent process may have to resume, but Zuse keeps the conversation history on your computer.
