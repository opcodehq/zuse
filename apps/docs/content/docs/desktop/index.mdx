The desktop app brings the agent conversation and the checkout it works in into one window. Its layout has three zones:

- the **sidebar** on the left, for projects, threads, connected computers, pull requests, and plugins;
- the **main area**, which shows the start screen or the open thread with its conversation tabs and the composer;
- the **right pane**, a set of tabs such as **Files**, **Diff**, **PR**, **Terminal**, **Browser**, **Simulator**, and **History**.

Panes can be resized and hidden with keyboard shortcuts. The top bar shows the thread's branch, which you can copy, and **Open in…** for opening the checkout in an editor, terminal, or file manager installed on your computer.

The desktop app runs on macOS, Windows, and Linux. Keyboard shortcuts in these docs use macOS keys; on Windows and Linux, use `Ctrl` where macOS uses `⌘`.
