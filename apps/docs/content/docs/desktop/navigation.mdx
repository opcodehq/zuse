## Sidebar

The sidebar lists threads under their projects. Select a thread to restore its conversation tabs and checkout. At the top:

- **New thread** (`⌘N`) opens the start screen for a new task.
- **New project** (`⌘O`) opens a folder, clones a repository, or creates a project from a template.
- **Plugins** opens the plugin catalog.
- **Pull requests** opens a board of pull requests across your projects.

You can create your own sections to group threads, and pin threads you return to often. Threads on other paired computers appear together in one section. A thread row shows when its agent is working or finished, even when the thread is not open. Hover a row to archive it.

The footer holds your account menu, update status, and local agent usage.

Press `⌘K` to search chats and run commands from anywhere. Press `Ctrl+Tab` and `Ctrl+Shift+Tab` to move between threads in the sidebar.

## Conversation tabs

Tabs appear inside a thread, one per conversation. Use **+** or `⌘T` to open another conversation in the same thread and checkout, and `⌘1` through `⌘9` to jump between tabs. Closing a tab does not delete the thread's work.

Press `⌘F` to find text in the conversation.

## Right pane

The right pane holds the tools for the thread's checkout. Use **+** in its tab strip to open:

- **Files** to browse and edit the checkout;
- **Diff** to review the checkout's changes;
- **PR** for the thread's pull request, when its branch has one;
- **Terminal**, which reads **Cloud terminal** for a cloud thread;
- **Browser** for local previews and websites;
- **Desktop** to watch a cloud computer's desktop;
- **Simulator** for an iOS Simulator or Android emulator on the thread's computer;
- **History** for the commit graph.

File paths and terminal working directories follow the thread's checkout, including its worktree.

Toggle the sidebar with `⌘B`, the right pane with `⌘⌥B`, the files panel with `⌘E`, and the terminal with `⌘J`. `⌘L` moves focus to the composer, and `⌘P` finds a file in the checkout.

## Settings

Open settings with `⌘,` or **Settings** in the application menu. See [User settings](/reference/settings) for every section.

Press `⌘/` to see all keyboard shortcuts, or open [Keybindings](/reference/keybindings).
