Use these guides when you know the outcome you want. Each one stays focused on a single workflow and tells you how to confirm it worked before you move on.

| Goal | Start here |
| --- | --- |
| Keep concurrent tasks isolated | [Run tasks in parallel with worktrees](/how-to/local-parallel-worktrees/) |

| Give an agent the right evidence | [Add files and context to a task](/how-to/local-add-context/) |

| Push, open a pull request, and merge | [Create and complete a pull request](/how-to/local-complete-pull-request/) |
| Resume after a setup, provider, or turn failure | [Recover or continue a local task](/how-to/local-recover-task/) |
| Set app preferences, worktree location, and project actions | [Configure local and project settings](/how-to/local-configure-settings/) |

For a normal feature task, create an isolated checkout, give the agent the required context, verify the running result when applicable, then review and ship the diff. Delegate only when the work has clean ownership boundaries.
