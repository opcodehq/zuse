Zuse runs your installed `pi` CLI in RPC mode and renders assistant text, thinking, tools, usage, and errors in the conversation timeline. Zuse requires Pi 0.85.1 or newer.

## Install and authenticate

Choose **Install** in **Settings → Providers & accounts**, or install it yourself:

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

Or:

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

Pi manages its own authentication. Run `pi` in a terminal and use `/login`, or sign in with **ChatGPT** from the Pi row. Environment variables for a model provider must be available to Zuse's process, not only to an unrelated terminal shell.

In Pi's settings, **Pi binary path** takes an absolute executable path; leave it empty to find `pi` on PATH. An invalid explicit path is reported as an error instead of silently launching a different installation. Update with `pi update --self`, or from the Pi row.

## Sessions and composer

- Start independent Pi sessions per project or worktree, stop active work, and continue the same conversation after restarting Zuse.
- Choose a model in the model picker. Thinking levels come from each model.
- Steer a running turn; your message is delivered at Pi's next step.
- Attach images for vision-capable models, or reference workspace files.
- Use Pi's own commands, such as `/compact`, from the composer.
- Answer Pi extension confirmations, selections, and text questions in Zuse.
- Discover skills from `.pi/skills`, `.agents/skills`, and `~/.pi/agent/skills` (or `$PI_CODING_AGENT_DIR/skills`).

## Permissions

Zuse installs a small access extension in each Pi process, so **Ask for approval** and **Full access** both work. With Ask for approval, file inspection (`read`, `grep`, `find`, `ls`) runs freely and every other tool asks first. To keep that guard reliable, restricted Pi runs don't load your other Pi extensions; Full access loads them as usual.

Plan mode and **Approve for me** are not available for Pi.

Native session files stay in Pi's session storage. If one is deleted or corrupt, Zuse reports an error instead of attaching another conversation, so keep those files when you move or back up your installation.
