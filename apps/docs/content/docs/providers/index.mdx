A provider is the coding agent behind a chat. Zuse ships twelve built-in agent integrations plus its own Zuse agent, and it can run any other agent that speaks the Agent Client Protocol (ACP). Every provider gets the same durable timeline, tool and edit rendering, model picker, worktrees, and review flow; models, slash commands, sign-in, and limits stay provider-specific.

| Provider | How Zuse runs it | Sign-in |
| --- | --- | --- |
| Zuse agent | Built into Zuse on macOS and Linux, no CLI | A connected ChatGPT or SuperGrok subscription |
| Claude Code | `claude` CLI | `claude /login`, a Claude setup token, or an API key; multiple accounts |
| Codex | `codex app-server` | `codex login` or an API key; multiple accounts |
| Cursor | Pinned `@cursor/sdk` runtime; needs `cursor-agent` installed | Sign in from settings, which mints a Cursor API key |
| Devin | `devin acp` | `devin auth login` |
| Grok | `grok agent stdio` | `grok login` |
| Hermes | `hermes acp` | `hermes auth add`, or ChatGPT or Nous Portal from settings |
| Kiro CLI | `kiro-cli acp` | `kiro-cli login` |
| Muse Code | `muse serve` (1.4.6 or newer) | `muse login` or `muse auth set` |
| OpenCode | `opencode serve` | `opencode auth login`, or ChatGPT or GitHub Copilot from settings |
| Pi | `pi` in RPC mode (0.85.1 or newer) | `/login` inside Pi, or ChatGPT from settings |
| Oh My Pi | `omp acp` | `omp login` |
| Antigravity | Google's `agy_acp_server`, installed by Zuse | Your Google account, from settings |

Zuse detects each provider and reports installation, sign-in, and update state in **Settings → Providers & accounts**. Agents you install later turn themselves on the next time you open settings or the model picker. Zuse does not bundle a paid provider subscription.

## Gemini

Gemini CLI is not a built-in provider. Add it from the ACP registry instead: open **Settings → Providers & accounts**, add an ACP agent, and search for **Gemini CLI**. See [ACP agents](/providers/acp#gemini-cli).
